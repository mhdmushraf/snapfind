# Snapfind

AI photo delivery for weddings and events: each guest sees only the photos they appear in.

**Live:** https://snapfind.linkzoneglobal.com

## Features
- Photographers upload event photos, including live during the event
- Guest takes a selfie; face matching returns only their photos
- AI culling flags blinks, blur and burst duplicates before review
- Multi-photographer accounts, couple album and family sets

## Tech
React, open-source face detection and matching, image processing, custom auth
